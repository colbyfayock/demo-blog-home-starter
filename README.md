# Demo Blog Home Starter

A Next.js homepage that displays a list of blog posts from `data/posts.json` with post excerpts and newsletter information.

## Use this template

```bash
npx create-next-app -e https://github.com/colbyfayock/demo-blog-home-starter
```

## Local setup

Install dependencies with Yarn, then start the development server:

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app. Use `yarn build` to build it and `yarn start` to run the production build.
